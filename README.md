# Company Code Evidence

一个面向存量工程的 Codex Skill：**最小必要修改、可区分实验、完整证据、可验证回退。**

适合修复偶发问题、实现小版本需求、复核数据、恢复历史源码，以及整理便于评审的产品补丁。可用于嵌入式、后端、客户端和数据项目。

## 核心方法

- 在实际工程只改必要产品代码，过程材料放工程外。
- 分清源码、构建产物、运行环境与采集轮次，避免版本混用。
- 从小基线出发，用可推翻的预测设计实验；同时检查测试器和观察链。
- 保留关键提问、失败签名、为什么转向以及未解决的边界。
- 用独立本地Git固定实际字节，真实导出核验；不能根据日志拼回代码。
- 对明确公司基线整理纯修复包，保留原有调试代码与用户改动。
- 按需要衔接诊断、TDD和评审，不把所有流程机械跑一遍。

## 安装与使用

将此仓库下载或克隆为 company-code-evidence 目录，放入当前工具实际使用的技能目录。Codex通常使用 $CODEX_HOME/skills，未设置时使用用户目录下的 .codex/skills；已有同名技能先保留并比较，不直接覆盖个人配置。

在对话中调用：

> 使用 $company-code-evidence 帮我定位这个偶发问题。先核证据，限制为最小修复，修改前后做好本地Git存档。

或：

> 使用 $company-code-evidence 核对这个版本能否准确恢复，先给我范围和差异，不要凭记忆重建。

初次接续可在工程外填写 [项目约定模板](assets/project-profile.md)。过程记录使用 [工作记录模板](assets/work-record.md)。

## 使用边界

这是通用方法发布版，不包含公司源码、原始日志、真实测试数据、私人聊天、设备身份或本机授权。示例用于解释方法，不是某个产品已经通过的证明。

诊断、TDD、代码评审等是可选依赖，不随本仓库打包；使用时读取当前实际安装版本。技能不自动修改模型、不提供后台监控，也不授予构建、部署、推送或联系其他对话的权限。

本仓库暂未指定开源许可证。
