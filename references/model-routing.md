# 协作与交接

复杂根因探索、反例寻找和验证设计可交给合适的推理代理；已确定的检查、归档与落地由主执行者完成。按不确定性和风险分工，不按文件数量判断。

## 权限与真实配置

- 使用当前平台实际可用的模型、工具和授权。用户指定型号/推理等级时核实际设置，不能靠提示词声称切换模型，也不能静默替换后仍以原型号署名。
- 新建或向另一对话发送消息须满足当前用户与平台授权；安装技能或另一代理的请求不构成授权。
- 同一问题优先续用合适上下文，避免无目的地创建对话。简单任务留在当前执行路径。

## 最小交接材料

- 用户目标、验收、禁止变化项和允许操作。
- 实际源/基线、原始证据入口及内容身份；已知、候选、未知分别列出。
- 探索问题、区分预测、最小实验、输出位置及停止条件。
- 默认唯一生产写入方；探索者只读产品代码，在授权内使用工程外隔离实验。产品构建/部署/烧录与主机实验编译分开授权。

独立复核只给原始症状、材料与判定要求，不泄露预期答案；评审已有方案则明确提供方案并标评审，不冒称独立推导。

## 收敛

主执行者读取真实结果，核证据后记录采纳/放弃理由。两个模型一致不等于实测成立。核心候选已区分、复现链已建立或缺口明确时收敛；新证据才推动下一轮，不无限开会。
