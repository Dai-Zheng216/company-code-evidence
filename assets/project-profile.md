# 项目约定模板

放在项目认可的工程外资料目录；不要把此空模板当作已授权配置。只填写本次需要的项，未知明确留空。

- 目标/验收、修改范围、不得改变的行为：
- 实际源码根、仓库根、构建入口、外部输入：
- 工程外资料根、当前状态与证据索引：
- 允许的源码修改、隔离实验、主机编译：
- 产品构建、部署/设备、提交/推送的具体授权：
- 独立Git存档范围、排除项、必要属性、关键节点快照：
- 公开测试接口及行为；是否授权代理在明确需求内选择测试边界：
- 无法快速复现时允许的受限分析和验收边界：
- 协作方式、模型偏好、另一对话的授权及唯一生产写入方：
- 原始数据的保存、共享和脱敏规则：
- 更新日期与本次适用范围：

用户的当前明确要求优先于旧模板。更换项目不能继承上一项目的路径、设备权限或发送授权。
